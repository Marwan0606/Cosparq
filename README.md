CoSparq.ai is an AI-powered idea and startup refinement tool. It helps entrepreneurs, students, and innovators take a raw startup idea and instantly improve it using AI. The goal is to spark creativity, validate feasibility, and save time in the brainstorming stage.

The app follows the followng structure:
1. User submits their raw idea (everything they have in mind)
2. The AI creates a scoreboard that scores the app based of 8 metrics, the user can highlight on any of the scores to get a justification of why they were given this score
3. The AI creates a market research page for the idea displaying the results in a clean and easy to read way using different panels. Again hovering upon each panel or section gives the user extra info about this section
4. There are still other pages in development such as the monetization page, business structure page and more which is all AI generated and displayed in a clean and easy to read way
5. The user also has access to an AI chatbot that is context aware of everything, it has access to the scores and any of the other pages and it also remembers all the previous interactions with the user. This AI chatbot is designed to help improve, develop and refine your idea


TECH STACK: 
Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express
Database: MongoDB
Authentication: JSON Web Tokens (JWT)
AI Integration: OpenAI API (for idea refinement)

To try to run this app you need a valid:
  openAI API key
  MongoDB connection link

  
In the .env you will need the following: 
  PORT number (choose any valid port number)
  MONGO_URI=your_mongodb_connection_string
  JWT_SECRET=your_jwt_secret
  OPENAI_API_KEY=your_openai_key

Once ready while in the backend folder in your terminal run npm start or node app.js
